这回是连载。

时间是为85BC冬，米特拉达梯役后，苏拉从希腊出发第二次进军罗马，也是著名的复仇之行。文章是以卢库卢斯的口吻讲述式地写成的 ，所以各位可以随意代入听众身份。涉及人物有大统（魔）帅（王）苏拉、高（多）贵（才）冷（多）艳（艺）的克拉苏以及小可（腹）爱（黑）庞培。另：玫瑰在古时象征着秘密。这篇文章也揭（编）示（造）了很多苏拉军中的小秘密，希望大家喜欢。

&nbsp;

我还能记起来，那一天的夜晚，是玫瑰色的。

如果英白拉多还在的话，肯定会用批评的语气打趣我说：“傻孩子。玫瑰色的天是夕阳时才会有的景色，怎么弄出夜晚来？”

不过这回我就要大着胆子告诉他，是真的，英白拉多，是真的。那一天的夜晚是玫瑰色的，而且它就倒映在您的眼睛里。

&nbsp;

卢修斯·李锡尼乌斯·卢库卢斯

&nbsp;

&nbsp;

幸福的过去，只是想一想就会令人不由自主地心中发烫。眼下正要入冬，军营四处散散乱乱地铺上了一些火堆，更多的则是被不断地送向英白拉多的帐里，因为大家都知道他缺不了这些。

&nbsp;

天暗得越来越快了，可再黑的夜都不能遮蔽住苍黄大地上的残枝败叶。那时候我们的心情就像这堆破草一样，毫无头绪。没有人知道未来在哪里，不过是在按照地图上的标识漫无目的地晃荡。“雄武之师”做出这种行径，却没有一个人感觉奇怪。英白拉多说要打回罗马，不过收不到任何信任的声音，当然也收不到怀疑，因为没有人敢去回答。

&nbsp;

我们每天都走，但最有经验的老兵都总结不出行军里数、物资消耗这些最平常的细节，于是只能拜托克拉苏做这件事。这孩子精于计算，我一直知道。据说他在受困于岩洞的那九个月里居然还坚持在石壁上练习演算。同属李锡尼家族，但人与人的差异大概是天壤之别的吧。我当初若不是被数学家教天天体罚，也不会那么早就来参军。

&nbsp;

至于庞培吗？我会说的，最近总是有人问我关于他的事，其实这孩子除了狂妄自大之外也并非一无是处。我厌烦他，只不过是因为他狂妄得太过分了，竟然凡事都要用英白拉多的衣钵做挡箭牌，好像我们其他人都从未如他那般受过“苏拉的关爱和照顾”似的。

&nbsp;

不过说实话，他在讨英白拉多的欢心方面还真是自有一套秘法，无人能够效仿。每天的军务处理完后，英白拉多就顺势把他请到帐子里，像个骄傲的父亲一样静听他对他自己当天“成绩”的夸夸其谈。我和克拉苏就总守在帐门外面，那孩子手里抱着演算蜡版，一面写一面偷瞄我的表情。

&nbsp;

我能理解他对我的这种依赖，毕竟他还小的时候，我们就常常在家族集会上碰面；而自从他拼命逃出生天，辗转到希腊投奔英白拉多以来，也一直是我这个同族长辈照顾着他。他没那么好的命，天生就能被英白拉多喜欢，但训诫和指导却从没少过他的。

&nbsp;

想起来我参军的时候，英白拉多还只是个财务官，我们很快就熟络了。那时的他给不了人哪怕一点点的距离感，总是见到新朋友就兴奋地拉去喝酒。统帅苏拉和财务官苏拉之间存在的差别，比你能想到的还要大呢。总之，我们就在帐外等着，如同期盼心上人回心转意，不过始终都未能如愿。他们两个总能一起和睦地度过整个夜晚，真是令人羡慕。

&nbsp;

但克拉苏总是说“真是令人厌烦”。我问他是对谁这么说，他说是对天。天还不够冷，庞培这团柔滑的水还不足以冻成冰。等他冻成冰了，看英白拉多还敢不敢认他。

&nbsp;

我笑了，说今天等够了，我们还是回去吧。

&nbsp;

行军的路上赶上农神节，尽管资金严重不足，英白拉多也坚持要开庆祝会。这点上他和财务官苏拉的作风如出一辙。在严明至极的马略军中，他每次都是偷偷办活动，结果都是被大张旗鼓地否决。现在有了自主权，他就像提前开展报复似地全力筹备，从各处搜刮银两，就差上沿途门户里抢劫了。

&nbsp;

自然没人怠慢。赶路可以拖拉，享乐却得抓紧。没人知道自己明天还能不能活着醒来，于是群魔乱舞、歌声不断。累了就躺到人堆里喝酒，跟完全不认识此刻却倒在一起的同僚闲诌；醒了就回篝火旁载歌载舞。克拉苏见状就说自己要回帐里睡觉，我当时没拦他，后来想起就是无尽的“悔恨”……当然这是后话。

&nbsp;

英白拉多靠着一根长木，在这种情境下他通常都是很放松的，可这次不知为什么竟面无表情。庞培席地坐在离他三足远的地方，瞧见我来了，他的眉毛不自然地沉了下去。

&nbsp;

我慢慢靠近他们，英白拉多把头抬起来，从他的目光里我读不出任何东西，只能看到篝火倒映在他眼中现出的赤红。我轻轻唤他，他好像听见了，又好像没听见，只是下一瞬飞快地按住我的手腕，被酒浆浸染的喉咙里挤出了一声简短又嘶哑的“卢库洛”。

&nbsp;

我怔住了。虽然看不见，但我相信庞培也怔住了。顺着他的动作我屈下膝来，努力地在他面前维持着镇静听命的姿态。而英白拉多只是眯着眼睛对我笑了笑，上一次他对我露出这种表情，还是在马略的行伍里。

&nbsp;

是的，我相信他当时未免有些烂醉了，就如周围所有盲从着他的人一样。见我没有回应，他就呼出几声曾经财务官苏拉最常做的口哨，轻轻摆了摆略显沉重的手，紧接着我就听到庞培那略显浮夸的脚步声。

&nbsp;

转眼间这一小堆篝火前就仅剩我们两人，透过英白拉多的发隙，我相信我看到了玫瑰色的夜空。但我什么也没说，只是靠在他身旁，等着他讲话。

&nbsp;

不过，

&nbsp;

呼吸声。只有呼吸声。很快周遭的空气就都弥漫起了酒味。在这样的环境里，我有点昏昏欲睡。后来竟真的就这样睡着了，他也没有管。

&nbsp;

或许是他认为，我们两个之间已经不需要再多说什么了吧。

&nbsp;

后来的事，就是他找人把我抬到主帐里睡了一夜，还取笑我一直都神志不清，叫也叫不起。总之等我醒来的时候，听到的第一个声音竟然是厨师的，他怒气冲天地抱怨没有几个人醒来吃早餐，结果粥全干结成块了。

&nbsp;

“所以我昨晚和你说了，让你也跟大家喝点酒，这样不就同步了吗？”英白拉多只是笑他。

&nbsp;

又转过头对我说：“睡醒了，就别再拖沓。跟我出去转转吧。”

&nbsp;

“英白拉多，今晚我们还继续庆祝吗？”我很奇怪，明明喝多酒的是他不是我，怎么清醒的顺序倒过来了。

&nbsp;

“农神节七天的狂欢赶不上，两天倒是可以。主要是我看兵士们都走不动了，不鼓励一下，别说罗马，亚里亚德海恐怕都越不过。”

&nbsp;

“我感觉您很享受。”我尽量以最快的速度套上衣服。仆人们还都在呼呼大睡，看来今天不管发生什么，都只能靠我自己了。

&nbsp;

“是吗？”他顿了一会，“或许你说的对。卢库洛……”

&nbsp;

他就是喜欢这样叫我的名字。而且自从形成了这个习惯，就再没变过，即使到最后也是一样……哦，我大概说得太远了。

&nbsp;

我们走出去，我特意向克拉苏和我住的那顶帐篷望了望，不知怎的感觉有点心悸。

&nbsp;

我很想过去瞧瞧，但转头一瞥见英白拉多的脸，这种想法就消失殆尽了。和他单独在一起的机会只会越来越难得的，我深知这点。

&nbsp;

厨师迫于压力重新准备了全军的餐食，那些粥块则是喂了奴隶和马匹。众人围坐当中，英白拉多一宣布今晚继续庆祝的消息，立马传来了排山倒海的欢呼声。这群小乳孩，明明昨晚还都边吐边喊再也不喝酒了，结果在巴库斯面前还是会忘我地逸乐。但人性如此，不是么？

&nbsp;

可在长桌的另一端，我惊讶地望见克拉苏正和庞培坐在一块，两人都神色紧张，正在嘀咕着什么。这场景真是吓人——明明他们几个月都不能认真地说上一句话！

&nbsp;

我必须把这事问个明白。于是餐后，打着如厕的名号，我在小路上一把抓住克拉苏的袖子：“你都干了些什么？”

&nbsp;

“只是……聊一聊。”他把情绪隐藏得很好，我什么都看不出来。

&nbsp;

“我没别的意思，只是觉得你和庞培聊在一起太怪了。”

&nbsp;

“我们只是偶然碰见然后说了点话，前辈……我昨晚实在太累，所以一回帐篷就睡下了。”他似乎都知道我想问什么，于是就提前开始给自己打掩护，“您放心吧，我很好。”

&nbsp;

“他是有什么事求你吗？”但我穷追不舍，好像老家长一般喋喋不休地盘问孩子的情况。

&nbsp;

“我们两个谁也不欠谁。”

&nbsp;

“他如果问你关于他来之前英白拉多的事情，千万别轻易回答他……”

&nbsp;

“嗯，我记下了。谢谢您。”

&nbsp;

这孩子总是这么礼数周全，虽说有李锡尼亚的名门风范，但更多时候却是让人摸不着头脑。我内心挣扎着，怎么也要最后再嘱咐他一句。

&nbsp;

“今晚我就回去睡了，你如果有什么话想说的，到时候再告诉我也没问题。”

&nbsp;

他只点点头。

&nbsp;

天哪，你可以想见我当时有多绝望。就好像你费尽心机做了个沙堡，结果大浪一冲全没了。若不是这天剩下的时间一直都能和英白拉多同行，我简直就要发疯。克拉苏这孩子是有点心眼的，不好对付，但被攻克了之后也一定不好修复。总之到了晚上，宴会开始了，我就开始担惊受怕。

&nbsp;

不过幸好，我看见了克拉苏，只是——

&nbsp;

只是——他为什么还是和庞培走在一起？而且又是像早晨一样窃窃私语？你能理解我，当时我就想冲过去把这两个小畜生抓住逼问一顿，但限于形势还是忍住了。与其明处投枪，不如暗中放箭。我从旁边座席上抓来一块不知是谁的黑色斗篷，罩住身子就往那边小跑。那副模样肯定可笑至极，但我当时根本什么都顾不上了。

&nbsp;

藏在他们必经之路上的草丛后面，如此就可以听到他们交谈的内容。如果有不当话题出现，我再当场跳出就来得及。——请你忍一忍笑，因为我每次想起这个念头来都觉得当时自己傻极了，你如果笑得太激烈，我也会笑得讲不下去的。

&nbsp;

果不其然他们走过来了。我的全身立刻便如弓弦一般绷紧。只见克拉苏一下挡住了庞培的路，以威胁的语气对他低吼道：

&nbsp;

“你如果敢说出去，我赌上李锡尼亚家族的光荣，绝不会轻饶你。格奈乌斯。”

&nbsp;

庞培却毫不在意：“我哪有那么念念不忘？你和我说这么多次，不反而是在加深我的记忆吗？”

&nbsp;

听到这里我只感觉心脏咯噔一声。这是看见什么了？庞培哪有机会去见克拉苏？莫非他昨晚被英白拉多赶走了，对我心生怨念，于是去找克拉苏伺机报复，要攻击我们李锡尼亚全族？

&nbsp;

“总之你不许再想了。否则这次可不会放过你，格奈乌斯·庞培。”

&nbsp;

两个人愤愤地在岔路上分开了，我却忽然感觉眼皮一跳，不知是激动还是放松下来的反应。或许真的什么都没发生吧，我想。至多也只是小孩子的装神弄鬼而已。
