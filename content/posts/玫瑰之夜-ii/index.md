[原作2018.7.22-23]

不过事实证明我还是错了。傍晚时克拉苏又说要提前回去，我便一口应允下来，同时和他讲我今晚还是要陪英白拉多。他又只是点点头。

&nbsp;

猎物已到，准备收网。我看宴会进行得差不多了，便迅速转身离席（不用问，英白拉多当然还是和庞培坐在一起，聊得十分开心），快走几步后以全速冲向我们两个的营帐，像揭发盗贼的房主那样一把撇开帐帘——

&nbsp;

眼前的竟仿佛是另一个世界。玫瑰花瓣散落一地，庙里拆来的金色架台被严丝合缝地重新搭好，白烛在上面烧得通明。哦，还有，明显是被故意铺陈起来的巨型波斯地毯中央，有个纤瘦的少年手抱竖琴，正忘乎所以地踩着节拍舞蹈。

&nbsp;

那场面我这辈子都忘不了。真的，你应该去问问克拉苏，他现在还记得多少舞步。几十年来，我见过无数人在同样华美的陈设下舞蹈，也买过不少号称一绝的舞者，但却再没有受过那样强烈的震动。当时他的身体还是最匀称、最优雅的，卷发在脑后被梳得整整齐齐，上面还泛着香泥的晶莹闪光。至于面容，我稍微靠近了些，一向警觉的他此番居然没有留意到闯入者的存在——

&nbsp;

舞蹈仍在继续。我似乎看清了些，他很明显是涂了油膏，所以脸色要比平常红润得多。眉毛的边缘被刻意地修饰过；眼周则洒满了金粉，当他蔚蓝色的眼眸扑闪时，就宛如汇成了星河。以我这种凡夫俗子的品味来判断，可以说是他在一瞬间与天神的影子重合了。

&nbsp;

我很入迷，但按着军营里的规矩，这一切终该结束。在听到象征警告而非赞美的拍手声后，他猛地刹住了脚步，眼中的星河被打乱了，只剩下惊惧的余波。

&nbsp;

“马尔库斯。”我以亲人的语气轻声唤他，试图平复他的心情，不过无果。他完全、完全怔住了，就像个木偶那样无所适从。克拉苏不冷静的样子，我大概也只见过这一次，当然，是大概。

&nbsp;

“前……前辈……”他的声音抖得厉害，漂亮的脸此时略显扭曲，“请您听我……解释……”这严谨的青年这时连变位都差点说错。

&nbsp;

“坐下来吧，慢慢讲。”我怕再吓着他，于是就维持着以安慰他为主的态度，虽然内心还是很想教训他一顿。

&nbsp;

他坐下来，结果反而又不解释了。我问他，要不要先去换了衣服，把油膏洗掉。他有些不情愿地点点头，但还是以军人的态度飞快地起身去收拾残局。

&nbsp;

“幸好是被我撞见，别的将军要是看到了，非要打断你的腿不可。”

&nbsp;

我刚说完这句话，便意识到一丝异常。莫非他昨天也在跳舞，然后被庞培发现了？

&nbsp;

他可能也意识到了我在怀疑什么，于是低声说：

&nbsp;

“请您不要顾我的脸面。”

&nbsp;

“别这样讲，好歹你也是李锡尼亚家的后裔，我不能不比对其他人都更在乎你的尊严，除非你自己放弃它。回到你自己说吧，还有谁知道这事？”

&nbsp;

“庞培。”他迅速地吐出这个名字，然后微微抬起眼，又在观察我的表情。

&nbsp;

“你瞒着我们练这个多久了？”

&nbsp;

“……其实从小我一直都不排斥舞蹈，也会几套动作……但是这样的练习，也是最近才开始的。”

&nbsp;

“那你的衣服和饰物都是哪里来的？”

&nbsp;

“积累。”他说了这么一个模糊不清的词。

&nbsp;

我揉揉额头，而后忽然想起来，有天他拎着个袋子去周边镇巷，结果很快就回来了。当时我还为此逗他的笑，他却没说话。结果这小子竟然是去抢脂粉去了。

&nbsp;

至于绸衣，也很好拿到，沿途的商铺里一抓一大把。其它的装饰用具也大都是战利品。如此看来，这件事其实很简单。只是做出这件事的“表演者”，会因他的本来身份而让旁人震动不小。

&nbsp;

“庞培和你说什么没有？”

&nbsp;

“他已经发誓要保守秘密。当然我也会一直盯着他的。”

&nbsp;

“马尔库斯啊。”我把他叫到我身前来，“你这是为了什么呢？”

&nbsp;

他做出个惨淡的微笑。意思大概是，您应当知道。

&nbsp;

“英白拉多确实喜欢歌舞，但你又不是奴隶，你是军官。想得到他的垂青，只有多立功才行。”

&nbsp;

“这个军团里的地位显然不是按照功劳大小排序的。”说这话时他的声音冷得出奇。

&nbsp;

我一惊。这孩子怎么听着有点像在可怜我？随统帅征战多年，交情最深、恩情最切的副将的地位，居然在骄慢的小孩子面前显得不堪一击。我不会说我忌妒庞培的，我从来都没有忌妒过他，毕竟会说漂亮话也是种本事，有时甚至比赫赫军功还要有力。

&nbsp;

“那你也算是冒险了。如果英白拉多还是不高兴，你名誉上的损失可是永久的。”

&nbsp;

“我知道。但我实在没有别的办法。”他弯下腰来，“当我求您，前辈……给我一个机会，让我帮助我们两人。”

&nbsp;

多说无益。我只能拍拍他的肩膀，示意他我默许了支持他。

&nbsp;

克拉苏的眼睛里却忽然扫过一星失落的光，与那些极尽谄媚之辈相比，他显然知道自己在做什么。然而我知道这孩子最大的毛病，就是总爱拿琥珀去换宝石。两者从价值上比较或许并无高下，但得失相抵，在我看来并不算什么好事。我并不是在诅咒这样一个出色的后辈，而且事实上我比任何人都要渴望看到他的成功——但是，以我到了这个年岁所拥有的眼光，可以看见他终有一天会为这种冒险的习惯付出刻骨铭心的代价。

&nbsp;

咳，我不求天神的宽恕，但还是让我们回归正题吧。之后的几天里，我的日程是白天用来行军，晚上则用来检查舞蹈练习。我是克拉苏唯一的观众，他就在我的注视下如暮春的彩蝶般拼力起舞。整晚我们互相都不说一句话，也不去管帐篷外发生的事，两人都沉浸在了军人本不该享受的节拍中。

&nbsp;

终于有一夜，我回到帐篷，但克拉苏已然不在里面，与歌舞相关的一切用具也都不见了。一瞬间思绪的惊雷击中了我，使我知道他去了何处。

&nbsp;

用最不济的心灵也能想明白，今晚是他唯一的机会。就在上午，庞培私自带一队士兵上了小路，因此受到了伏击，造成人员与物资损失。英白拉多训斥了他一顿，但他认为自己并没有错，而是伏击本身在任何场景下都有可能出现。这种宛如国王与大将之间的争吵弄得整个军队都惶惶不安。扎营后，英白拉多就好像丢了魂似的，径直回到自己的帐里，一声也不吭。

&nbsp;

我奔出去，虽说这种行动没人能帮得了他，但作为前辈，我无论如何也要确保克拉苏不会在紧急时陷入孤立无援的境地。

&nbsp;

这时我看到一队乐师也在向英白拉多的帐篷行进。这孩子或许是给自己做了些伪装混入其中了吧，愿神蒙佑他。

&nbsp;

英白拉多准许我进了帐篷。他正靠在一张精致的躺椅上，目光疲惫且无力。他唤我到他身边坐下，简单的贴面礼过后，搂住了我的肩膀：

&nbsp;

“我做错了吗？”

&nbsp;

我不敢回答。虽然在庞培来之前，我们两个还是可以无话不谈的。

&nbsp;

“说吧。是不是今天这副情景，也遂你的意？”

&nbsp;

“我没有这样的想法，英白拉多。我只是，单纯地来看看您，希望可以像从前一样安慰您。”

&nbsp;

“是我对那孩子依赖得太多了。”他叹了口气，“以为他真是天神派来的使者，无所不能。可大家不都还是凡人么。”

&nbsp;

“我们都会犯错，英白拉多。如果您能意识到，那么就再好不过。”

&nbsp;

“嗯。”虽然这个回答也是叹出来的，但他看起来认同了我的说法。

&nbsp;

“你们其他人没有怪罪我的吧？”半晌之后他又开口了。

&nbsp;

“我们无心批判您，只是不想您被蒙蔽。”

&nbsp;

“哦？”他似乎来了兴趣，“庞培那个小家伙还成了你们老将的绊脚石了，对吧？看来我想的不错。”

&nbsp;

“对真正忠实的士兵来讲，与统帅的关系不是非亲密无间不可的。只有缺乏能力的人才常常琢磨它。”

&nbsp;

“我发现你越来越懂说话的艺术了，卢库洛。你们都是一样，越来越懂。”

&nbsp;

“……是我做错了，英白拉多。”我只和他说了最后这样一句。

&nbsp;

乐师连番入帐。麻醉、欢悦、逸乐、沉沦，一切错误的情感也连番冲撞着我们的耳膜。英白拉多垂着头，似乎听得很入神，但我渐渐地坐不住了。别用太崇拜的眼神看我，并不是我的品味有多高雅，而是我担心克拉苏——他现在在哪儿呢？他难道真要和这些小厮一起给英白拉多跳舞么？他是否在极严厉地拷问自己的心灵呢？

&nbsp;

有几个舞者上来了。我努力地在那一群亮片衣裳之间寻找熟悉的骨架——可是没找到。我忽然有点放心，可能这孩子打消主意了？

&nbsp;

歌舞队渐渐散去，但没想到就在这时几个弹琴和吹笛的乐师满脸不情愿地回到我们面前，重新摆好了架势。我还没来得及叫出声，一个纤瘦的蒙着面纱的舞者就踩着维纳斯的步调轻快地靠近。

&nbsp;

英白拉多把头抬了起来。
